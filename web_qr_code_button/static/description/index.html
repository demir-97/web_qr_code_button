QR Code Button — A “Show QR Code” Action for Any Record

Settings › Technical › QR Code Button: pick a model, save. A "Show QR Code" action now appears in the gear (Actions) menu of every record of that model, opening a popup with a full-size QR code ready to print, save or scan.

✓ Odoo 17.0✓ Odoo 18.0✓ Odoo 19.0

How it works

  1. Go to Settings › Technical › QR Code Button.
  2. Pick a model (and, optionally, a Char/Text field to encode instead of the record link). Save.
  3. Open any record of that model › gear icon › Show QR Code.

What's encoded

  • By default: a link back to the record — scan it and the record opens.
  • Optionally, pick a Char/Text field on the model (serial number, reference, asset tag, ...) and the QR code encodes that value instead — handy for asset labels, product tags, warehouse bins.

Technical

The QR code is rendered by Odoo's own barcode engine (the same one behind invoices' payment QR codes) — no external service, no new dependency. Turning a rule on creates a small ir.actions.server bound to the chosen model, which is how it appears in the model's Actions menu without touching any view. Turning it off unbinds the action without deleting it.

Frequently asked questions

Does generating the QR code need an internet connection?
No — it's rendered entirely server-side by Odoo's own barcode engine, no external service is called.
Can I print the QR code?
Yes, the popup shows a full-size, print-ready code you can save or send straight to a printer.
What happens if I disable a rule?
The action is unbound from that model's Actions menu but not deleted — re-enabling the rule restores it instantly, no reconfiguration needed.
